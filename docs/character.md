# Character guidelines

Novi should look and feel the same everywhere it appears: in the app, in the README, and in anything shared about the project.

## Silhouette

- Small, compact body that reads clearly at icon size
- Large, upright ears with dark inner ears and cream tufts
- Full tail with a cream tip
- Cream muzzle, chest ruff, and cheeks
- Dark paws
- Large dark eyes with a single soft highlight

## Palette

| Role | Color | Hex |
| :-- | :-- | :-- |
| Main green | Fur | `#C7E86B` |
| Cream | Muzzle, chest, tail tip | `#F5F1E6` |
| Ink | Inner ears, paws, eyes | `#2A2B26` |
| Near-black | Primary background | `#0E0F0D` |
| Charcoal | Surfaces and panels | `#161714` |

The lime green is used sparingly in interface and brand work. It belongs to Novi first, and to accents second.

## Expressions

| Expression | Intended moment |
| :-- | :-- |
| Neutral | Listening, idle on the desktop |
| Happy | Acknowledging a note or a good review |
| Curious | Asking a follow-up question |
| Determined | Recalling a plan the user set for themselves |

## Motion

- Prefer small gestures: blinks, ear flicks, head tilts, a slow tail sway
- Keep idle motion infrequent so Novi never distracts from charts
- Avoid bouncing, flashing, or anything that reads as an alert

## Things to avoid

- Changing Novi's proportions, colors, or markings between assets
- Neon effects, glowing circuitry, or crypto imagery
- Placing Novi next to price predictions or performance claims
